clearWebStorageSnapshot method

Future<void> clearWebStorageSnapshot()

保存している WebStorage の写しを削除します。

ProxyConfig.enableWebStorageInheritance で受け渡した写し（画面の localStorage など）を、利用者のサインアウトや端末の引き渡しの前に 消すために使います。稼働中かどうかと設定によらず呼び出せます。

  • 写しの暗号化 Box を開いている場合（有効な設定で稼働中）は、記録を 消して Box を圧縮します。
  • 開いていない場合は、暗号化 Box（proxy_web_storage_secure）と 0.25.0 までの平文の Box（proxy_web_storage）をファイルごと削除します。 この isolate の別のインスタンスが開いている Box は、閉じずに記録を 消して圧縮します。

ファイルを消す・圧縮するだけで、フラッシュ上の物理的な消去は保証 しません。暗号化の鍵や他の保存領域には触れません。

Throws:

  • CacheOperationException 削除に失敗した場合（operation は clearWebStorageSnapshot）。

Implementation

Future<void> clearWebStorageSnapshot() async {
  try {
    // 段階 2 が Box を開く処理や復旧 API と重ならないよう、初期化と同じ
    // 直列化に入る
    await _storageInitializationLock.synchronized(() async {
      final directoryPath = await _resolveStorageDirectoryForMaintenance();
      // 開いている Box（稼働中のこのインスタンスのものを含む）は閉じずに
      // 空にして圧縮し、開いていない Box はファイルごと削除する
      for (final name in [
        _encryptedWebStorageBoxName,
        _legacyWebStorageBoxName,
      ]) {
        await _clearOrDeleteBox(name, directoryPath);
      }
    });
  } catch (e) {
    throw CacheOperationException(
      'clearWebStorageSnapshot',
      'WebStorage の写しの削除に失敗しました: $e',
      e is Exception ? e : null,
    );
  }
}
